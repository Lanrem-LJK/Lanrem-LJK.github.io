This interactive code sample presents two selected scripts from my master's thesis that I believe demonstrate my practical ability to build a machine learning workflow for biological sequence data. The project overview appears in this panel, while the complete Python source files can be viewed using the tabs alongside it. Together, the scripts form one connected pipeline, from protein sequences to fixed-size representations and a trained three-class classifier.

Background and purpose

My master's thesis addressed two related questions: whether a protein is metal-binding, and, if it is, whether its function is enzymatic or structural. The code shown here approaches both questions within one three-class task. Each protein is classified as an enzymatic metal-binding protein, a structural metal-binding protein, or a non-metalloprotein.

Protein sequences have variable lengths, whereas conventional machine learning models require fixed-size inputs. The first script therefore converts each sequence into a numerical representation using ProtBERT. The second script trains a class-weighted XGBoost model on these representations. This design connects protein language model embeddings with an interpretable supervised learning workflow and accounts for differences in the number of training examples across the three classes.

Files and execution order

Order File Purpose
1 1_extract_embeddings.py Converts labelled protein sequences into fixed-size ProtBERT embeddings for three-class classification.
2 2_train_xgboost.py Trains, selects, and evaluates class-weighted multiclass XGBoost models using the generated embeddings.

Run 1_extract_embeddings.py first. Its three output CSV files are the inputs to 2_train_xgboost.py.

Input

Sequence data

The datasets are stored outside this code sample. Their locations are supplied through command-line arguments. The embedding script expects a directory with predefined training, validation, and test splits:

/path/to/dataset_original/
├── pident30_total_train.txt
├── pident30_total_val.txt
└── pident30_total_test.txt

Each line contains a protein identifier followed by its amino-acid sequence:

1b4u_A_pos_enz,MTEKKER...
2abc_B_pos_stru,VLSPAD...
3xyz_C_neg_enz,MRLVKAA...

The identifier is mapped to one of three labels:

Label Identifier pattern Class
0 pos_stru Structural metal-binding protein
1 pos_enz Enzymatic metal-binding protein
2 neg Non-metalloprotein; neg_enz and neg_stru are combined in this class

Rows that do not contain one of these patterns are skipped. Dataset construction and sequence-level split generation occur before this workflow and are outside this code sample.

Representation source

The embedding script supports three ProtBERT sources:

  • bert: the pretrained Rostlab/prot_bert_bfd model;
  • adapter: ProtBERT with a trained adapter supplied through --adapter_path; and
  • weights: ProtBERT loaded with a local checkpoint supplied through --weights_path.

A transformer layer can be selected explicitly. Each sequence is represented either by its [CLS] vector or by mean pooling across residue embeddings.

Processing workflow

1. Extract protein embeddings

The following example extracts mean-pooled representations from layer 23 of the pretrained model:

python 1_extract_embeddings.py \
  --data_dir /path/to/dataset_original \
  --out_root /path/to/outputs/embeddings_3class \
  --model bert \
  --mode pool \
  --layer 23 \
  --device cuda

For each data split, the script:

  1. reads protein identifiers and sequences;
  2. assigns the three class labels from the identifier patterns;
  3. formats and tokenizes the amino-acid sequences for ProtBERT;
  4. performs batched inference without gradient calculation;
  5. selects the requested transformer hidden layer;
  6. reduces the variable-length token representations to one fixed-size vector per protein; and
  7. writes the identifiers, labels, and embedding features to CSV.

The example command produces:

/path/to/outputs/embeddings_3class/raw_pool/
├── train.csv
├── val.csv
└── test.csv

Each CSV uses the following structure:

id,label,f0,f1,...,f1023

The training split must contain all three labels, and the train, validation, and test CSV files must use the same feature columns.

2. Train and evaluate XGBoost

python 2_train_xgboost.py \
  --train /path/to/outputs/embeddings_3class/raw_pool/train.csv \
  --val /path/to/outputs/embeddings_3class/raw_pool/val.csv \
  --test /path/to/outputs/embeddings_3class/raw_pool/test.csv \
  --models_dir /path/to/outputs/xgboost_3class_models \
  --select_metric accuracy

The training script:

  1. loads the embedding features and maps the labels to integers {0, 1, 2};
  2. calculates inverse-frequency weights from the training split so that each class has equal total influence during fitting;
  3. searches combinations of learning rate, tree depth, row sampling, column sampling, and L2 regularization;
  4. trains multiclass XGBoost models on a CUDA GPU;
  5. uses validation multiclass log loss for early stopping;
  6. records validation accuracy and macro-averaged precision, recall, and F1;
  7. selects the best configuration by validation accuracy or macro F1; and
  8. evaluates the saved models on the held-out test split and exports predictions from the selected model.

The class weight for class c is calculated only from the training data:

weight(c) = total training samples / (number of classes × samples in class c)

This weighting changes each class's contribution to model fitting without duplicating or removing sequences. Validation and test samples remain unweighted.

Output

The workflow produces:

  • train.csv, val.csv, and test.csv, containing protein IDs, three-class labels, and ProtBERT features;
  • serialized XGBoost models for the evaluated hyperparameter combinations;
  • validation_summary.csv and test_summary.csv, containing accuracy and macro-averaged precision, recall, and F1; and
  • best_model_test_predictions.csv, written inside --models_dir and containing the selected model's predicted label for each test protein.

Together, these outputs preserve the path from the original amino-acid sequence and class annotation through representation learning, model selection, and final three-class prediction.

Requirements

  • Python 3
  • PyTorch, Hugging Face Transformers, and AdapterHub adapters
  • NumPy, pandas, and scikit-learn
  • XGBoost 3.x with CUDA support
  • A CUDA-capable GPU for the intended execution path

#!/usr/bin/env python3
"""
Generate fixed-size ProtBERT embeddings for three-class classification.

This is step 1 of the code sample. The generated feature tables are used by
`2_train_xgboost.py`.

* Supports raw ProtBERT-BFD, an Adapter-tuned model, or local model weights.
* Two embedding modes:
    1. 'cls'  – take the [CLS] token of a chosen transformer layer.
    2. 'pool' – mean-pool the residue embeddings of that layer.

Input
=====
The dataset is supplied separately. `--data_dir` must point to a directory
containing `pident30_total_{train,val,test}.txt`.

Plain-text rows look like:
    1b4u_A_neg_enz,MTEKKER...
    2abc_B_pos_stru,VLSPAD...
    3xyz_C_pos_enz,MAGVEK...

Each row contains `protein_id,amino_acid_sequence`. Labels are inferred from
the protein identifier:
    0 = pos_stru  (structural metal-binding protein)
    1 = pos_enz   (enzymatic metal-binding protein)
    2 = neg       (non-metalloprotein; includes neg_enz and neg_stru)
Rows without one of these identifier patterns are skipped.

Output
======
`--out_root` controls the output location. The script creates:
    <out_root>/<raw|adapter|weights>_<cls|pool>/train.csv
    <out_root>/<raw|adapter|weights>_<cls|pool>/val.csv
    <out_root>/<raw|adapter|weights>_<cls|pool>/test.csv

Each CSV row:
    id,label,f0,f1,...,f{d-1}

Run
===

    --data_dir /path/to/dataset_original \
    --out_root /path/to/outputs/embeddings_3class \
    --model bert --mode pool --layer 23 --device cuda

Author: 2025-07-10

import argparse
import csv
from pathlib import Path
from typing import List, Tuple
import torch
import numpy as np
from adapters.composition import Stack
from adapters import BertAdapterModel
from transformers import BertTokenizer
from transformers import BertModel


MODEL_NAME = "Rostlab/prot_bert_bfd"
MAX_LEN = 2048          # maximum tokens (residues) per sequence
BATCH_SIZE = 8          # GPU memory permitting


# ---------- Adapter loader -------------------------------------------------- #
def trained_adapter_bert(model_name: str, adapter_path: str):
    """Load a ProtBERT model with a pre-trained adapter."""
    model = BertAdapterModel.from_pretrained(model_name)
    model.load_adapter(adapter_path, with_head=True)
    model.active_head = "AdapterBERT_head_adapter"
    model.set_active_adapters(Stack("AdapterBERT_adapter"))
    return model


# ---------- I/O helpers ----------------------------------------------------- #
def read_dataset(path: Path) -> Tuple[List[str], List[str], List[int]]:
    """
    Read ID, SEQ from a TXT file and keep three classes.

    Labels:
      0 = pos_stru
      1 = pos_enz
      2 = neg  (covers both 'neg_enz' and 'neg_stru')

    NOTE: Do NOT use -1 for a real class. Many losses (e.g., CrossEntropyLoss)
    expect class indices in [0, num_classes-1]. Use 2 for 'neg'.
    """
    ids, seqs, labels = [], [], []
    with path.open() as fh:
        for line in fh:
            line = line.strip()
            if not line or "," not in line:
                continue
            prot_id, seq = line.split(",", 1)

            # Map id → label
            if "pos_stru" in prot_id:
                label = 0
            elif "pos_enz" in prot_id:
                label = 1
            elif "neg" in prot_id:  # matches 'neg_enz' or 'neg_stru'
                label = 2
            else:
                continue  # skip unknown pattern

            ids.append(prot_id)
            seqs.append(seq.strip())
            labels.append(label)
    return ids, seqs, labels


def write_csv(path: Path, ids: List[str], labels: List[int], embs: np.ndarray):
    """Write embeddings to disk; path parent dir is created if absent."""
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", newline="") as fh:
        writer = csv.writer(fh)
        d = embs.shape[1]
        header = ["id", "label"] + [f"f{i}" for i in range(d)]
        writer.writerow(header)
        for prot_id, lab, vec in zip(ids, labels, embs):
            writer.writerow([prot_id, lab] + vec.tolist())
    print(f"[+] Saved {path}  shape={embs.shape}")


# ---------- Embedding extraction ------------------------------------------- #
def sequences_to_embeddings(
    ids: List[str],
    seqs: List[str],
    model,
    tokenizer,
    layer_idx: int,
    mode: str,
    device: torch.device,
) -> np.ndarray:
    """
    Convert sequences to fixed-size vectors.

    mode:
        'cls'  -> [CLS] of layer idx
        'pool' -> mean of token embeddings (excluding [CLS]/[SEP]) of layer idx
    Returns:
        (N, D) ndarray
    """
    model.eval()
    all_vecs = []

    # ProtBERT expects residues separated by space, e.g. "M G D V ..."
    spaced = [" ".join(list(s.upper()))[: MAX_LEN * 2 - 1] for s in seqs]

    with torch.no_grad():
        for i in range(0, len(seqs), BATCH_SIZE):
            batch_seqs = spaced[i : i + BATCH_SIZE]
            enc = tokenizer(
                batch_seqs,
                return_tensors="pt",
                padding=True,
                truncation=True,
                max_length=MAX_LEN,
            ).to(device)

            out = model(
                **enc,
                output_hidden_states=True,
                return_dict=True,
            )
            hidden = out.hidden_states[layer_idx]  # (B, T, D)
            attn = enc["attention_mask"]          # (B, T)

            for h, m in zip(hidden, attn):
                # h: (T, D)  m: (T,)
                if mode == "cls":
                    vec = h[0]  # CLS position
                else:  # 'pool'
                    real_len = m.sum().item()
                    tok_embs = h[1 : real_len - 1]          # exclude CLS/SEP
                    vec = tok_embs.mean(dim=0)
                all_vecs.append(vec.cpu().numpy())

    return np.vstack(all_vecs)  # (N, D)

#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
Step 2: train and evaluate class-weighted three-class XGBoost models.

Purpose
-------
Use the ProtBERT feature tables created by ``1_extract_embeddings.py`` to
classify proteins as structural metal-binding (0), enzymatic metal-binding (1),
or non-metalloprotein (2).

Input
-----
The train, validation, and test CSV paths are supplied with ``--train``,
``--val``, and ``--test``. These datasets are not bundled with this code sample.
Every CSV must use the same feature columns and the schema:

    id,label,f0,f1,...,f1023

Training
--------
The script computes inverse-frequency sample weights from the training split,
performs a GPU XGBoost grid search with the ``multi:softprob`` objective, and
uses validation multiclass log loss for early stopping (500 rounds). Models are
selected by validation accuracy or macro F1. Accuracy and macro-averaged
precision, recall, and F1 are reported on validation and test data.

Output
------
``--models_dir`` controls the output location. It contains:

    xgb_<hyperparameters>__A<validation_accuracy>__F1<validation_macro_f1>.pkl
    validation_summary.csv
    test_summary.csv
    best_model_test_predictions.csv

Example
-------
python 2_train_xgboost.py \
    --train /path/to/embeddings_3class/raw_pool/train.csv \
    --val /path/to/embeddings_3class/raw_pool/val.csv \
    --test /path/to/embeddings_3class/raw_pool/test.csv \
    --models_dir /path/to/outputs/xgboost_3class_models \
    --select_metric accuracy

Dependencies
------------
XGBoost 3.x with CUDA support, pandas, NumPy, and scikit-learn.
"""

def ensure_dir(path: str):
    if not os.path.exists(path):
        os.makedirs(path, exist_ok=True)

def infer_feature_cols(df: pd.DataFrame):
    return sorted([c for c in df.columns if re.fullmatch(r"f\d+", c)],
                  key=lambda x: int(x[1:]))

def map_labels_to_int3(s: pd.Series) -> pd.Series:
    """
    Map label column to integers {0,1,2}.
    Accepts either textual labels ('pos_stru','pos_enz','neg') or numeric 0/1/2.
    """
    if s.dtype.kind in {"O", "U", "S"}:
        return (s.astype(str).str.strip()
                .map({"pos_stru": 0, "pos_enz": 1, "neg": 2,
                      "0": 0, "1": 1, "2": 2})
                .astype(int))
    return s.astype(int)

def load_split(path: str):
    if not os.path.isfile(path):
        sys.exit(f"[ERROR] CSV not found: {path}")
    df = pd.read_csv(path)
    df.columns = [c.strip() for c in df.columns]

    feat_cols = infer_feature_cols(df)
    df["label"] = map_labels_to_int3(df["label"])
    df.dropna(subset=["label"] + feat_cols, inplace=True)

    X = df[feat_cols].astype(np.float32).values
    y = df["label"].values
    ids = df["id"].astype(str) if "id" in df.columns else pd.Series(range(len(df)), name="id")
    return X, y, ids

def compute_metrics(y_true, y_pred):
    A = accuracy_score(y_true, y_pred)
    P, R, F1, _ = precision_recall_fscore_support(
        y_true, y_pred, average="macro", zero_division=0
    )
    return {"A": A, "P": P, "R": R, "F1": F1}

def metrics_to_str(m):
    return f"A={m['A']:.4f} P={m['P']:.4f} R={m['R']:.4f} F1={m['F1']:.4f}"

def param_dict_to_name(params, val_metrics):
    parts = [f"{k}-{str(v).replace('.', 'p')}" for k, v in sorted(params.items())]
    parts.append(f"A{val_metrics['A']:.4f}")
    parts.append(f"F1{val_metrics['F1']:.4f}")
    fname = "xgb_" + "__".join(parts) + ".pkl"
    return fname[:240] + ".pkl" if len(fname) > 255 else fname

def build_param_grid(grid_dict):
    keys = list(grid_dict.keys())
    for vals in product(*(grid_dict[k] for k in keys)):
        yield dict(zip(keys, vals))

# CHANGE signature to receive n_classes
def fit_and_validate(param_set, X_tr, y_tr, X_val, y_val, sample_weight, n_classes):
    """Train one XGBClassifier using XGBoost 3.x early-stopping API (multiclass)."""
    model = xgb.XGBClassifier(
        objective="multi:softprob",   # <- multiclass probabilities
        num_class=n_classes,          # <- IMPORTANT for multiclass
        tree_method="hist",
        device="cuda",
        n_estimators=N_ESTIMATORS_MAX,
        early_stopping_rounds=EARLY_STOP_ROUNDS,
        random_state=RANDOM_STATE,
        eval_metric=EVAL_METRIC_INTERNAL,
        **param_set,
    )

    model.fit(
        X_tr, y_tr,
        sample_weight=sample_weight,
        eval_set=[(X_val, y_val)],
        verbose=False,
    )

    best_iter = model.best_iteration or model.n_estimators
    y_pred = model.predict(X_val, iteration_range=(0, best_iter + 1))
    mets   = compute_metrics(y_val, y_pred)
    return model, mets, best_iter

def train_and_validate_all(grid_iter, X_tr, y_tr, X_val, y_val,
                           models_dir, select_metric,
                           sample_weight, n_classes):
    ensure_dir(models_dir)
    results, best_score = [], -np.inf
    best_meta = {}

    for i, params in enumerate(grid_iter, start=1):
        print(f"[{i}] Params: {params}")
        model, mets, rounds_used = fit_and_validate(
            params, X_tr, y_tr, X_val, y_val,
            sample_weight, n_classes
        )
        print(f"    Val: {metrics_to_str(mets)}  |  Early stop at round {rounds_used}")

        score = mets["A"] if select_metric == "accuracy" else mets["F1"]
        model_path = os.path.join(models_dir, param_dict_to_name(params, mets))
        with open(model_path, "wb") as f:
            pickle.dump(model, f)
        print(f"    Saved: {model_path}")

        result_row = {**params,
                      "val_A": mets["A"], "val_P": mets["P"],
                      "val_R": mets["R"], "val_F1": mets["F1"],
                      "best_iteration": rounds_used,
                      "model_path": model_path}
        results.append(result_row)

        if score > best_score:
            best_score, best_meta = score, result_row
            print(f"    >>> New BEST so far ({select_metric}={best_score:.4f})!")
        else:
            print(f"    (No improvement. Best remains {select_metric}={best_score:.4f})")
        print()

    return results, best_meta["model_path"]

def evaluate_all_models(models_dir, X_test, y_test):

                         "test_A": mets["A"], "test_P": mets["P"],
                         "test_R": mets["R"], "test_F1": mets["F1"]})
    return pd.DataFrame(rows).sort_values(["test_A", "test_F1"], ascending=False)

def save_predictions(model, X, ids, out_csv):
    preds = predict_best(model, X)
    pd.DataFrame({"id": ids, "prediction": preds}).to_csv(out_csv, index=False)

def parse_args():
    p = argparse.ArgumentParser(description="GPU XGBoost 3.x grid search with early stopping.")
    p.add_argument("--train", default=DEFAULT_TRAIN_PATH)
    p.add_argument("--val",   default=DEFAULT_VAL_PATH)
    p.add_argument("--test",  default=DEFAULT_TEST_PATH)
    p.add_argument("--models_dir", default=DEFAULT_MODELS_DIR)
    p.add_argument("--select_metric", choices=["accuracy", "f1"],
                   default=SELECT_METRIC_DEFAULT,
                   help="Metric for best‑model selection")
    return p.parse_args()

###############################################################################
# main                                                                        #
###############################################################################

def main():
    args = parse_args()
    ensure_dir(args.models_dir)

    print("=== Loading data ===")
    X_tr, y_tr, _   = load_split(args.train)
    X_val, y_val, _ = load_split(args.val)
    X_te,  y_te, ids_te = load_split(args.test)
    print(f"Train: {X_tr.shape}, Val: {X_val.shape}, Test: {X_te.shape}\n")

    # === Compute & display class distribution, then derive per‑sample weights ===
    unique, counts = np.unique(y_tr, return_counts=True)
    class_counts = {int(cls): int(cnt) for cls, cnt in zip(unique, counts)}
    print("=== Training class distribution ===")
    for cls, cnt in class_counts.items():
        print(f"Class {cls}: {cnt} samples")
    n_samples  = len(y_tr)
    n_classes  = len(class_counts)
    class_weight = {cls: n_samples / (n_classes * cnt) for cls, cnt in class_counts.items()}
    sample_weight_tr = np.vectorize(class_weight.get)(y_tr)

    grid_iter = build_param_grid(USER_PARAM_GRID)
    print(f"Total combinations: {np.prod([len(v) for v in USER_PARAM_GRID.values()])}\n")

    results, best_model_path = train_and_validate_all(
        grid_iter, X_tr, y_tr, X_val, y_val,
        models_dir=args.models_dir,
        select_metric=args.select_metric,
        sample_weight=sample_weight_tr,
        n_classes=n_classes
    )

    # Validation summary
    val_csv = os.path.join(args.models_dir, "validation_summary.csv")
    pd.DataFrame(results).to_csv(val_csv, index=False)
    print(f"Validation summary written to: {val_csv}")

    # Test evaluation
    print("\n=== Evaluating saved models on TEST ===")
    test_df = evaluate_all_models(args.models_dir, X_te, y_te)
    test_csv = os.path.join(args.models_dir, "test_summary.csv")
    test_df.to_csv(test_csv, index=False)
    print(test_df.to_string(index=False, float_format=lambda x: f"{x:.4f}"))
    print(f"\nTest summary written to: {test_csv}")

    # Predictions for best model
    print("\n=== Generating test predictions for best model ===")
    best_model = load_model(best_model_path)
    pred_csv = os.path.join(args.models_dir, "best_model_test_predictions.csv")
    save_predictions(best_model, X_te, ids_te, pred_csv)
    print(f"Predictions saved to: {pred_csv}")

if __name__ == "__main__":
    main()
